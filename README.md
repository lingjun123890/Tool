# 影梭社区版

基于原作者开源项目二次开发的社区版本，以下仅列出本版本**新增/改进**的功能。

## 新增功能

- 地图 SDK 整体迁移：百度地图 → 高德地图（地图 / 定位 / 搜索）
- 路线悬浮窗可缩小为浮球，避免遮挡地图视线
- 路线转弯使用二次贝塞尔平滑切角，画线轨迹与实际行走轨迹一致
- 新增「画笔画路线」：手指直接在地图上手绘路径，自动抽稀、抬手后平滑重绘
- 跑步模拟支持随机配速与跑走交替（5 项参数可在设置中调整）
- 地图 Key 不写入源码：首次使用引导填写，仅保存在本机，运行时注入，任意高德 Key 均可使用
- 修复路线悬浮窗标记闪烁消失、覆盖物频繁重建等问题
- 路线绘制改为增量更新，长路线更流畅
- 「关于」页面展示开源地址与 GPL v3 协议说明
